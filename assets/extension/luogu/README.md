# 洛谷记录导出（可选）

一个极简浏览器扩展：**把当前打开的洛谷评测记录页导出成 JSON 文件**，
再交给教练导入。

---

## ⚠️ 先说风险，再说怎么用

**这一条请看完再决定装不装。**

| 风险 | 说明 |
|---|---|
| **洛谷的 ToS 不欢迎抓取** | 洛谷的服务条款对自动化抓取是禁止的。本扩展不抓取，但也属于"工具化地取数据"，**存在解释空间** |
| **有封号先例，而且是真实的** | 这个项目的最初版本用服务器代理 + 浏览器直连抓记录，**账号被封过**。这不是理论风险 |
| **本扩展做得更轻，但不等于零** | 它只读**你屏幕上已经显示的内容**，不发任何额外请求（详见下）。风险显著低于爬虫，**但不为零** |
| **出问题只能自己担** | 本扩展和 acmer-coach 都不提供任何担保 |

**要不要用，你自己判断。** 如果你不想承担这个风险，
也有别的路：手动记几道题、或者只关注 CF（CF 有官方公开接口，一点风险没有）。

### 为什么说它比爬虫轻得多

| 做法 | 发请求？ | 洛谷看到的 |
|---|---|---|
| 爬虫 / 脚本 | ✅ 大量 | 一个不正常的客户端在高速拉数据 |
| 早期版本（已废弃） | ✅ 有 | 服务器机房 IP 在拉数据 |
| **本扩展** | ❌ **一个都不发** | **和"用户自己在看页面"完全一样** |

具体地说：扩展**没有 `host_permissions`，没有任何 fetch/XHR**。
它做的事只有两件 —— 读当前页面 DOM 里已经存在的那个 `<script>`，
然后让你下载一个文件。

## 装

1. 浏览器开 `edge://extensions`（Edge）或 `chrome://extensions`（Chrome）
2. 打开右上角「开发人员模式」
3. 点「加载解压缩的扩展」，选**本文件夹**
4. 打开任意洛谷页面 → 右下角出现「📥 导出洛谷记录」

## 用

1. 打开**你自己的**评测记录页：`www.luogu.com.cn/record/list?user=你的uid`
2. 点右下角那个按钮
3. 浏览器下载一个 `luogu-<uid>-<日期>.json`
4. 把文件交给教练，说：

   > 导入这个文件：`C:\Users\你\Downloads\luogu-1855438-2026-09-29.json`

   或者直接让教练调 `coach_import`，参数 `path` 填那个路径。

## 已知限制

**只导出当前这一页。** 洛谷的记录页是分页的，按钮导出的是**你打开的那一页**
（通常是最新的 20 条左右）。要更多记录，得逐页打开再各点一次。

为什么不自动翻页：那就要发请求了 —— 而「发请求」正是上面表里风险最大的那一档。
**宁可麻烦一点。**

## 导出格式

一个 JSON 数组，直接就是 `coach_import` 认的格式：

```json
[
  {"platform":"luogu","problem_id":"P1001","verdict":"12",
   "submitted_at":"2026-09-01T10:00:00.000Z","time_ms":0,"language":"lang28"}
]
```

`verdict` 保留的是**洛谷的原始数字码**（`12` = AC）——
扩展不做解释，映射成 AC / 不 AC 是插件那边的事（见 `lib/setup.js` 的 `normalizeRecord`）。
这么分是因为：**判断逻辑只能有一份**，放在扩展里就是第二份。

## 排障

| 现象 | 原因 |
|---|---|
| 「这个页面上没有记录数据」 | 你不在记录页上。URL 里要有 `/record/list` |
| 右下角没有按钮 | 扩展没启用，或者页面不是 luogu.com.cn，或者没刷新 |
| 改了代码没生效 | 扩展页点 ↻ 重新加载，然后刷新洛谷页面 |
| 导出的条数比预期少 | 见上面「已知限制」—— 只导当前页 |

## 文件

| 文件 | 职责 |
|---|---|
| `manifest.json` | MV3。**没有任何 host_permissions** —— 它连不出去 |
| `content.js` | 读当前页内嵌数据 + 下载按钮 |

---

## 和本项目其它部分的关系

**这个扩展是可选的。** 教练本身不需要它 ——
CF 用户完全用不上（`coach_setup sync` 直接拉官方公开接口）。

它的存在只是因为：**洛谷和牛客没有公开的提交记录接口**，
而"读过哪些题"这条数据对教练有用（`coach_pool` 靠它排除你做过的题）。

如果你有别的办法拿到这份数据，只要能凑成上面那个 JSON 格式，
就完全不需要这个扩展。
