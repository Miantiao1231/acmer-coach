# rc.25 提示词与运行链核对

本轮已修复时间传递、空训练进度丢陪伴背景、旧仲裁开关误报，并核对当前 DSH NEXT 原生组装后的请求。没有调用真实 DeepSeek 或 Hindsight，没有读取正式聊天，也没有用隔离检查替代用户体验验收。

## 这次实际截到了哪一层

从本机 `DSH NEXT/resources/app.asar` 读取公开运行时代码，在仓库 `.preview-work/host-prompt-capture/host` 隔离解出依赖。当前 AgentLoop、SystemPrompt 均为 `0.2.1-rc.3`；没有用仓库所解析到的另一份旧 DSH SDK 冒充 NEXT。

在隔离目录加载原生 Session、AgentLoop、SystemPrompt、Tools、文件服务、工作目录、agent-instructions、技能和 time-context，接入当前插件。模型路由名称保留 `deepseek-official/deepseek-flash`，但 `prepareCall().stream(request)` 由假服务接住；所有 fetch 拦截，Hindsight 仅返回手写夹具。

因此捕获的是原生 `buildRequest → preparedCall.stream` 的完整 messages/tools，不只是静态 section 的注册列表。没有捕获正式用户会话、全部个人插件组成，也没有经过真实 provider 的 HTTP 序列化或服务端分词。以下字符数不是 token 或账单。

## 核对与修改

| 位置 | 确认的问题 | 当前处理 |
|---|---|---|
| `interaction-log` 与 `reflection-batch` | 底层裁剪/保存偷偷换成电脑当前时间，使传入时间的调用与恢复不一致 | 传入时间贯通读写和恢复；文件锁仍用实时墙钟 |
| `registerStateHook` | 已有空进度文件时提前返回，连档案和约定一起漏掉 | 保留陪伴背景，只停止首次建档提示 |
| `personLines/memoryLines` | 档案称呼与旧边界可能写成压过当前表达的指令 | 用户当前明确更正优先，旧资料只作相关背景 |
| 旧仲裁设置 | 已停用的仲裁链仍可能显示实际开启 | 兼容存储保留，`effective.arbiter=false`，回执说明未运行 |
| 时钟注入 | 宿主时钟、Hindsight 旧桥和陪伴当前时间重复 | 用公开 `timeContext` 投影检测原生时钟；已有原生时钟时只留互动间隔，旧宿主降级不变 |

静态 `coach:persona` 和 `coach:rules` 各注册一份；选中预设的 persona 前缀只引用这两份。工作区 AGENTS/CLAUDE 指令由宿主另行注入，技能目录由宿主提供，技能全文按调用进入后续请求。不能只修改插件文件就假设所有外部技能规则同步了。

本机 `algorithm-mentor` 旧技能确实要求固定六步、每步确认、先问后讲，并每题自动生成题解和文件。原生 `skill` 工具读取后，这段完整内容出现在下一次模型请求中，会与当前带教方针冲突。本机修订为跟随当前卡点、小例子和图引出模型；是否追问、给完整推导或导出文件由当前要求决定，沿用 agent 人格。主动草稿冷稿重写也取消了“先给情绪或称呼，再给内容”的固定顺序。

## 离线捕获结果

| 场景 | 验证到的结果 |
|---|---|
| 纯闲聊，已有空训练进度 | 保留角色名和称呼约定，没有首次建档提示 |
| 建模求助，模拟 Hindsight | 角色背景与一份召回均保留，不按本地账本屏蔽召回 |
| 原生技能工具调用后的下一步 | 修订后的技能正文实际进入 tool 消息，旧六步要求已去掉 |
| 模拟主动唤醒 | 不追加普通训练背景，避免两套当前行动要求互相干扰 |

四个场景均只有一份原生时钟，没有旧 `<runtime>` 时钟。前三个场景各一份 `coach_state`；主动唤醒为零。构造的服务组合共 41 个工具，其中 37 个来自小鲸，另 4 个为原生文件和技能工具；这不是正式会话的工具总数。

原技能加载后的工具结果为 2866 字符，修订后为 893 字符。原生 section 中小鲸人设 1581 字符、教练规则 3870 字符；本轮没有为凑缩短比例而删掉训练证据边界。

现行个人预设和随包预设均已静态核对：没有另嵌旧父女人设，保留宿主工具与 agent-instructions/技能机制。规划、委派等其他插件的条件提示未在本次最小组合中全部启用，不能据此断言正式长会话不存在其他提示词干扰。

本机 `.dsh/AGENTS.md` 也已静态核对：主要保存个人事实、交流偏好和本机边界，人格及教学原则引用插件，没有重嵌六步带教流程。捕获使用合成工作区指令，未把其中的私人事实复制进夹具或报告。
