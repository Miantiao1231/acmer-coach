# 中国区比赛资料索引

来源：用户整理的56场公开比赛资料，2026-10-12接入。原始工作表保持不动。

这里保存资料候选，按需打开对应赛事，不随每轮对话全部注入。链接存在或HTTP成功不证明比赛身份和题解正确。只有读过题面、题解并记录逐题模型的条目，才进入 CONTEST_PROFILES.yaml 的 solutionReviewed 覆盖。

覆盖2019—2026：45场区域赛、7场EC-Final、4场邀请赛。邀请赛作为补充，省赛、网络赛和同题镜像不重复算区域赛样本。赛事年份按原赛季，不因重赛举办年改写。

现场榜、CF练习榜和UCup重赛榜分别核对身份；判断奖牌门槛需要对应现场榜。题目通过比例不是未来出题概率。

已修正2024杭州的UCup错配：Stage8 Cangqian为浙江省赛，真正的2024杭州区域赛是Stage25 Hangzhou、场次1893。其他未核实条目保留候选身份。
