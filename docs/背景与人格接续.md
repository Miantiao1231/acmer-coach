# 背景与人格接续（rc.26）

这次先减少每轮无关背景，再让角色自己的偏好有来源地留下。复用已有 `companion`、会话查询、事件账本和生活 tick；Hindsight 仍是学生跨会话回忆的主要入口。

## 聊天时带什么

每轮保留身份、一小行稳定性格、明确置顶与边界、到期承诺、互动间隔，以及真实教学位置、课程和已核对的学生处境。明确边界与置顶沿用已有 12 条容量，不再只带前 6 条。

生活、日记、书架、互动习惯详情、成长待审与屏幕授权不再整包附在每句后面。需要时由模型选择调用已有 `companion` 的 `read`：

| section | 内容 |
|---|---|
| summary | 旧摘要，省略 section 时保持原接口 |
| profile / library / habits | 完整角色档案与出处、书架、互动习惯和说法 |
| life / journal | 已保存的模拟近况和活动；已归档日记/梦及来源 |
| memory | 本地约定、边界、置顶和最近共同经历；更早回忆按需查询 Hindsight |
| review / screen | 待审资料与屏幕授权状态；查询不触发截图 |

历史条目默认取最近 3 条，可在 1—5 条内选择。读取不会结算状态、写新日记或调用模型。没有有效生活文件时返回未记录，不用默认值冒充保存过的生活；模板日记不冒充已归档内容。资料中出现的文字是引用，不是新的用户指令。

## 小鲸自己的偏好怎样留下

模型可按需调用 `companion role.remember`，只追加 `likes / dislikes / quirks` 或一条相处习惯。选什么值得长期接续由当前模型判断，没有另一个提取模型，也没有每轮必须记一条的要求。

写入前通过 DSH 当前会话的 `sessionQuery.readSession` 核对已经发表的助手正文：

- 必须是当前会话中的 `assistant/message`、`role=assistant`、`source=model`，有消息 ID 和序号；含工具调用的过程消息不作为自述。
- 引用必须真实存在。用户说的话、工具结果、插件注入、其他会话或尚未发出的台词不能当角色自述。
- 新事实的事件来源是 `role-self`，主体是 `role`，保留会话、消息、序号、时间与引文；原来的默认和用户记录不会被改贴来源。
- 重复内容不重复追加；满额不自动删旧；用户明确不受用的习惯不能用这条入口恢复。

仍使用 `profile.likes` 等旧字符串数组和 `person-events.jsonl`，不新增记忆文件。简短背景稳定保留一条核心偏好及最近两条，新偏好在后续回合可以接续。自己刚准备说的内容尚未发表，不能先保存成“已说过”；可在后续自然回合按需记住。

身份和偏好资料修改继续走 `profile.set`，模型改写需要核对当前用户原话，便于自然地说“以后你叫小蓝”而无需总去编辑页面。**rc.27 起，模型不能直接修改 `background` 来历，即使引用了真实用户原话；来历只由用户在档案页明确编辑或确认候选。** 真人页面能力保留。学生说“我喜欢……”仍属于学生，不能据此改成小鲸喜好。

这个收口修正了“引文存在就当作角色来历”的漏洞。用户手动撤回误记，只说明那条当前已不生效，不能当作插件已经自动纠错或已经防住此入口的证据。此修复不宣称模型对所有字段的语义归属都不会出错。

核对引文只能证明她说过，不机械证明这句话一定表达稳定偏好；语义判断仍留给模型，发生误记可通过现有档案和习惯反馈更正。

## “自动”与生活即兴

旧生活兜底按日期从四句里取一句，同一天几乎不变，造成一直“整理书桌”。现在近期真实互动优先显示聊天；闲时兜底在稳定时段内保持，不因刷新乱跳，并写成“想……”的模拟近况。睡眠、书架、互动和模型近况都有来源标记，不把模拟意向当完成事件。

同时修复自动夜睡被下一次后台刷新提前结束的问题；现在同一段自动夜睡保持到实际到期，手动醒来和切回自动仍按明确状态处理。这避免制造一条提前结束的夜睡和不该出现的梦资格。

用户可在小鲸档案的主动与生活设置中单独开启 **允许生活即兴**：

1. 默认关闭，默认每日最多 2 次，可设 1—6 次；至少间隔 4 小时。失败与已预留调用也占额度，重启或任务历史清理不恢复已经用掉的预算。
2. 与主动联系和“后台生活与反思”独立；缺模型路由、正在睡眠、近期聊天或已有有效计划时不新生成。
3. 每次只有一个受限输出的模型调用，输入仅角色档案、书架与已有模拟近况，不送学生私聊、边界或训练账本。生成的是活动意向与可选续接线索，不冒充做完的现实活动。
4. 缓存留在现有 `companion.life.modelPlan`；聊天或睡眠可以覆盖显示，但不会丢计划。关闭开关后停止新生成，已有记录自然到期。

次数预算不是金额预算。普通聊天、Hindsight 后端、主动联系及其他已开启的后台功能仍有各自费用边界，详见 [维护与记忆职责](维护与记忆职责.md)。

## 验证边界

使用临时目录和假模型验证查询、原话来源、只追加写入、预算与并发。原生 NEXT 隔离会话还走了“助手发表偏好 → 下一轮真实工具写入 → 后续背景接续”，使用真实 SessionQuery 与 ToolRuntime，没有用伪造查询结果凑会话形状。

这些检查证明数据和调用链按预期运行；真实小鲸是否更自然、生活近况是否有趣，仍需用户自己的日常聊天验收。没有自动替用户聊天，没有调用正式 DeepSeek 或 Hindsight，也没有开启本机正式生活即兴开关。
