# rc.29：审查问题修复记录

本地预览，未发布。沿用 DeepSeek、DSH 的已有能力和 Hindsight 主召回；没有新增人格层或另一套记忆引擎。

## 14 项确认问题的处理

| 编号 | 原问题 | 当前处理 |
|---|---|---|
| 1 | 记忆请求未经脱敏 | retain、自动/手动 recall、派生查询统一复用现有 redact；持久待写内容先脱敏。不声称正则能识别全部语义隐私。 |
| 2 | 保存失败丢失且状态误报 | 复用 task-queue 持久补发，按 endpoint/bank 隔离、稳定 document_id；每条最多 3 次尝试，首次失败后按既有 60 秒、5 分钟退避。召回与保存状态分开。 |
| 3 | 游标被当成已学证据 | 只认显式 learned/verified 与本次明确声明；当前游标不自动补全任何前置掌握。 |
| 4 | 至少讲 10 分钟与固定顺序 | 删除最低时长和返回中的固定讲法。保留正整数、总预算与新知识点先有讲解计划的校验。 |
| 5 | 所有概念必须先查 Wiki | 改为按需核对；未搜到只代表本地索引无结果，不替代题意推理和知识判断。 |
| 6 | 失败复检自动撤旧验证 | 保存本次分数、用时与独立性，保留旧状态和历史；是否退化由新证据支持的另一次判断决定。超时标签只描述结果，不自动叫“不熟”。 |
| 7 | 判因强制三选一 | category 可省略，默认待确认；旧值兼容，引用与 quote-only 边界保留。待确认不自动安排练习。 |
| 8 | 手动睡眠提前结束 | 后台传递仍有效的 mode/since/until；旧记录缺睡眠片段时也按明确期限恢复，不被默认午睡时长截断。 |
| 9 | 崩溃恢复绕过重试上限 | 恢复与领取均检查次数，耗尽保留 failed，明确 retry 才重新授权；状态写盘失败不报完成。 |
| 10 | 阅读回执串书 | 生成与归档使用阅读活动自己的材料快照；当前书仅作变更提示，缺可信材料不借用别本书。 |
| 11 | 并发重复写、失败回执被缓存 | 可选 operation_id 在 SQLite 互斥下重新核对；accepted=false、ok=false 不缓存。异常或回执无法缓存保留待核对标记，不自动重做。 |
| 12 | 学生事实来源 ID 丢失 | 本次改变的事实保留核对的会话/消息/序号与引文；排除自动身份迁移和无关并发变化。置顶在原工作流项保存出处，不新造事实类别。 |
| 13 | 开发同步清单后补导致遗漏 | 所有清单在第一次比较/复制前完成，删除重复项，补当前相关检查和本记录；完整安装仍按包清单校验。 |
| 14 | 撤日程重复追问原因 | 仅在原因未知且影响安排时再确认，已有解释不重复问，保持不擅自重排。 |

## 复核中一起修的边界

- 队列满时，只在容量压力下回收最老 done/cancelled；不静默挤掉排队、运行或失败的待处理内容。仍满则明确失败。
- finish、cancel、retry、恢复等路径以实际写盘结果为准。失败任务也可被用户明确取消，避免无法处理的警告永久占位。
- 后台长任务执行期间每 60 秒只续自己的租约；失租、停止或恢复后发现被接管时，不再发起后续模型调用、发送消息或写旧结果。draft、重写、judge、fallback、日记/梦及阅读回包边界都核对。
- 已经发出的请求不能撤销服务端处理；租约、稳定 ID 和本地缓存不等于任意崩溃窗口的全局恰好一次。
- 主动稿只能按给定角色近况分享。没有材料可聊想做的事，不补造外出、读完或完成经历。

## 记忆失败后怎么处理

`coach_status` 分别给出召回和保存状态，待写/失败不再被读取成功盖掉。`accepted` 只表示后端接受请求，不代表已完成提炼。

沿用现有任务工具：

```text
coach_task action=list queue=memory
coach_task action=retry queue=memory id=...
coach_task action=cancel queue=memory id=...
```

不返回聊天正文。仅在用户明确要求时重试；重试可能产生后端提炼费用。关闭记忆桥不发请求，换库不把旧内容转投新库。待写内容在 `DSH_HOME/data/acmer-coach/tasks.json`；容量有限，磁盘不可写或全部积压时明确报错，不能保证本地存储损坏后仍能恢复内容。

## 本轮验证

- 已确认问题的隔离复现转成聚焦回归，逐项先失败再修复；覆盖教学、判卷、出处、记忆补发、并发、队列、睡眠、阅读和失租边界。没有用测试镜像替代真实对话。
- 使用实际 NEXT 公共运行时捕获合成教学请求：新工具定义进入模型入口，Wiki 强查、10 分钟门槛、判因三选一、撤日程必追问已去掉；模型输出由本地占位程序代替。
- 当前皮肤层级和人格设置在独立无界面浏览器夹具中检查，网络全部拦截。入口位于装饰层上方、可点击；生活即兴开关独立且默认关闭，表单保存无页面错误。没有操作正式 DSH 界面。
- VP 账号切换、迟到同步、工作区迁移和账本写失败等既有隔离检查通过；不等于所有数据库、VP 或安全边界已穷尽。

## 正式环境的只读核对

用户明确允许后，只读核对最近一段小鲸会话及服务配置，没有发消息或修改历史。

- 本机 Hindsight `/health` 与当前 bank 的 `/config` 均返回 HTTP 200；没有调用 recall/retain，也没有触发真实提炼。可达不等于保存、召回语义质量已验收。
- 最近会话的最新系统段已是新版伙伴设定；历史中仍有早期父女文本，未删除或改写。旧历史存在不等于最新系统提示仍要求父女关系，也不能保证模型完全不受历史影响。
- 正式会话没有压缩事件，无法借这段会话判断真实压缩后会不会遗留旧指令。模型人格与教学效果、真实休眠送达和正式双进程长期使用仍由用户验收。

## 使用边界

安装新副本后需重启 DSH 才加载静态规则与模块。长期旧会话若继续受旧语气影响，可以在更新后新开会话；Hindsight 与事实账本提供接续，不自动删除原对话。

本轮不推送 GitHub、不发布 npm、不更换模型、不启用新的付费功能，也不清理或重写用户的正式记忆与对话。修复 14 项已确认问题不代表整个插件已经不存在其他问题。
